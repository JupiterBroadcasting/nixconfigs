# Linux Unplugged NixOS Configurations

NixOS configuration examples from [Linux Unplugged](https://linuxunplugged.com) episodes.

## Configurations

- **[lup-0650-clinic-config/](lup-0650-clinic-config/)** - Episode 650: Home router with Home Assistant OS VM and Nebula VPN
- **lup-0631.nix** - Episode 631: Paperless-ngx with AI, Karakeep, Pinchflat, and ErsatzTV
- **nextcloud.nix** - Nextcloud setup with ACME SSL
- **nginx-ssl.nix** - Nginx reverse proxy with Cloudflare DNS-01 SSL
- **pihole.nix** - Pi-hole running in Podman

Each configuration is production-tested but shared as learning examples. Customize for your environment.
